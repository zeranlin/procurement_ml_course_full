第一课 · 第 1 阶段：模型到底在“学习”什么？

X、Y、样本、模型、Loss、参数、梯度与泛化

XY样本模型Loss参数梯度与泛化

一、先从高度上理解：机器学习到底在学什么？

机器学习 = 从有限历史样本中寻找一个能够泛化到未知样本的映射规律。
X ──→ Model fθ ──→ Ŷ │ ↓ 与真实 Y 比较 ↓ Loss ↓ 调整参数 θ ↓ 面对没见过的新 X ↓ 能不能继续有效？ Generalization

政府采购领域的第一个训练任务可以非常简单：输入一个供应商资格条件，输出“是否存在潜在不合理限制风险”。从专家视角看，这已经包含了机器学习的全部骨架：任务定义 → 数据 → 模型 → 反馈 → 参数更新 → 泛化。

第一层专家认知：不要先问“用什么大模型、多少 GPU”。先把任何问题还原成 X → Y：模型看到什么？我们希望它最终做出什么判断？

二、Sample 与 Dataset：数据不是文件，而是“经验”

一条经过专家确认的训练数据：

输入 X：供应商须在项目所在地设有分公司。
正确答案 Y：存在潜在风险（1）

这就是一个 Sample（样本），数学上写作 (x₁, y₁)。如果有 10,000 个这样的案例：

D = {(x₁,y₁), (x₂,y₂), …, (x₁₀₀₀₀,y₁₀₀₀₀)}

这就是 Dataset（数据集）。真正需要建立的认知不是“我有多少 PDF”，而是：

数据量 ≠ 经验量。高质量的反馈，通常比简单堆积文件更值钱。
低价值原始文件

10 万份采购 PDF，如果没有任务、标签和有效反馈，并不自动等于 10 万条监督训练经验。

高价值专家样本

原条款 + 上下文 + 风险标签 + 风险类别 + 法规依据 + 判断理由 + 修改建议，可以同时训练多种能力。

三、X 与 Y：任务定义决定了你究竟在训练什么

1. 什么是 X？

X 是模型在做判断时能够看到的信息。政府采购中，X 可能只有一句条款，也可能包含：

X = [条款文本, 采购标的, 项目类型, 采购方式, 履约地点, 项目背景, 上下文, 时间, 地区]

如果真实判断需要上下文，而训练时只给模型一句话，那么模型不可能凭空使用它没看到的信息。

信息上限原则：模型能力的上限首先受到输入信息约束。Insufficient Information → Unreliable Prediction。

2. 什么是 Y？

Y 是 Ground Truth / Label，也就是我们告诉模型什么才是“正确答案”。最简单：

Y = 1 → 有风险 Y = 0 → 无风险

更成熟时，Y 可以升级为：

Y = {
  是否风险,
  风险类别,
  风险等级,
  法律依据,
  理由,
  修改建议
}
标签就是老师。

如果专家把大量真正有风险的案例错误标成“无风险”，模型会被系统性教错。模型不会自动知道“老师的答案册写错了”。

四、Model 与 Parameters：训练真正改变的是什么？

先不用神经网络。假设我们人为定义三个特征：

  • x₁：是否出现注册资本限制
  • x₂：是否要求本地机构
  • x₃：是否限制企业成立年限

最简单的模型可以写成：

z = w₁x₁ + w₂x₂ + w₃x₃ + b

其中 w₁、w₂、w₃、b 就是模型的 Parameters（参数），统一写成 θ。

例如“注册资本不得低于 5000 万元”可以编码成 X=[1,0,0]。如果当前 w₁=0.2，模型对这个因素的内部风险评分就很低。

训练模型不是把知识复制进模型；训练真正发生的事情，是数据通过错误反馈不断改变参数 θ。
训练前：w₁=0.2, w₂=0.1, w₃=0.3
训练后：w₁=2.31, w₂=1.87, w₃=1.46

五、Prediction、Loss 与 Gradient：模型为什么会从“不会”逐渐变成“会”

假设真实样本：

X：注册资本不得低于5000万元
Y：1（风险）

模型预测 Ŷ=0.2。我们必须量化“错了多少”，这就是 Loss。为了直觉理解，先用平方误差：

Loss = (Y - Ŷ)² 当 Y=1, Ŷ=0.2：Loss=0.64 当 Y=1, Ŷ=0.9：Loss=0.01

Loss 告诉我们错得多严重，但还不告诉我们参数应该怎么改。Gradient（梯度）提供：

  • 方向：某个参数增大/减小时，Loss 会向哪边变化？
  • 敏感程度：这个参数对 Loss 的影响有多大？
θ(new) = θ(old) - η · ∇θ L

η 是 Learning Rate。可以把训练想成下山：Loss 是高度，Gradient 告诉你坡度，学习率决定一步走多远。

学习 = Error Correction。

Prediction → Error → Loss → Gradient → Parameters Update。重复几十万、几百万次后，参数逐渐形成数据中稳定的规律。

六、Generalization：真正的能力不是“背会”，而是“遇到新题还能做对”

假设模型在训练数据里发现了一个错误捷径：

“凡是出现数字的资格条件 → 风险”

训练集中很多风险条款恰好有“5000万元”“10年”等数字，于是模型取得很高训练分数。但遇到：

“供应商须提供 7×24 小时故障响应服务。”

如果这个要求结合项目场景是合理的，模型仍可能因为“数字”而误报。

模型学到相关性，不等于学到了真正希望它掌握的业务规律。Correlation ≠ Causation。

真正要追求的是：

面对真实未来分布 P(real) 中没见过的数据，模型仍然具有较低错误率。

这就是 Generalization（泛化）。

七、为什么需要 Train / Validation / Test？

数据集角色模型是否反复看
Train教材 + 练习题，用于直接更新参数会
Validation模拟考试，用来选模型、调超参数、观察过拟合间接参与开发决策
Test最终考试，用来评估真正泛化尽量不要在开发中反复看

政府采购领域尤其要防止 Data Leakage。一个项目往往同时有采购公告、招标文件、更正公告、中标公告、质疑答复、投诉处理决定。如果这些文件被随机拆到不同数据集，模型可能已经通过 Train 看过同一项目的线索。

项目级泄漏：

招标文件 → Train；投诉处理决定 → Test。表面是两个文件，本质可能是“同一道题拆到了不同试卷”。

因此真实项目里通常要按 Project ID 隔离，并在需要预测未来时采用时间切分。

八、本阶段对应的 5 个专家核心心智模型

心智模型专家真正关心的问题
① 数据 = 经验这条数据给了模型什么反馈？不是“有多少文件”。
② 信息决定上限X 是否包含做出正确判断真正需要的信息？
③ 标签 = 老师Y 是谁定义的？标注标准是否一致、是否可信？
④ 学习 = 减少 Loss我们通过 Loss 实际奖励了模型什么行为？
⑤ 能力 = 泛化没见过的新项目、新措辞、新领域还能不能有效？
训练模型 = 给模型大量精心设计的经验 + 告诉它哪里错了 + 不断调整参数 + 最终希望它对未知问题仍然有效。

九、本阶段小测与掌握标准

题 1：在“判断采购资格条件是否存在风险”中，X 与 Y 分别是什么？

X 是模型能够看到的输入信息；Y 是经过定义和标注的目标答案。根据任务不同，Y 可以是 0/1，也可以是风险类型、依据、理由等结构。

题 2：模型预测风险概率 0.2，专家标签为 1。Loss 的作用是什么？

把预测与目标的差异转成可优化的数字，为后续计算梯度和更新参数提供反馈。

题 3：训练过程中真正发生变化的是什么？

模型参数 θ，而不是原始文件、专家标签或法规本身。

题 4：Train 99.8%，Test 62%，模型好吗？

通常不好，说明训练与未知数据之间存在很大泛化差距，可能发生过拟合、泄漏或分布问题。

题 5：大量标签错误会怎样？

模型会系统性学习错误规律，因为训练目标本身就是错误的。

题 6：用自己的话解释“机器学习到底在学习什么？”

参考：它通过大量样本与错误反馈调整参数，寻找一个能把输入映射到目标并迁移到未知样本的规律。

十、深化理解：从“机器学习”再上一个高度

1. 新手和专家最大的认知区别

新手

数据放进去 → GPU 计算 → 模型“学会”。

专家

任务定义 → 数据分布 → 模型假设 → 优化目标 → 泛化。模型只是这个系统的一部分。

2. Hypothesis Space 与 Inductive Bias

模型不是凭空创造规律，它只能在自己的“假设空间”里寻找解释。一个线性模型能表达的关系有限；一个更复杂的神经网络能表达更复杂的函数，但也更容易记住噪声。

模型复杂度 ↔ 任务复杂度 ↔ 数据规模

Inductive Bias（归纳偏置）回答：“在有限数据之外，模型凭什么相信某种规律会继续成立？”

模型典型归纳偏置
线性回归/逻辑回归倾向用较简单、近似线性的边界解释数据
决策树倾向通过一系列规则切分空间
CNN倾向利用局部空间结构
Transformer通过 Attention 学习上下文之间的关系

3. 人类学习和机器学习为什么很像？

人：看 1000 个采购案例 → 总结经验 → 面对新项目 → 依据经验判断
机器：看大量 (X,Y) → 参数变化 → 形成统计表示 → 面对新 X → 输出预测

区别在于，人可以明确说出规则；神经网络的经验往往分布式编码在大量参数中，而不是一条条 IF-THEN 规则。

4. 大语言模型仍然没有逃出第一课

GPT 类预训练依然是 X→Y：

X = 前面的 Tokens Y = 下一个 Token 模型：P(next token | previous tokens) Loss：预测 Token 分布与真实 Token 的差异

几十亿、几千亿、几万亿 Token 的训练，仍然只是不断执行“预测 → 错误 → 梯度 → 参数更新”。复杂能力来自规模、数据和表示的叠加，而不是脱离了机器学习基本规律。

5. 第一阶段毕业的 6 个问题

  1. 什么是 X？
  2. 什么是 Y？
  3. 什么是模型 fθ？
  4. 为什么需要 Loss？
  5. 训练到底改变了什么？
  6. 为什么训练集表现很好不等于模型真的好？
如果你能不看笔记，用政府采购案例解释这六问，就已经建立了机器学习第一层“专家操作系统”。

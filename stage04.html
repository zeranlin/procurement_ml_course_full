第一课 · 第 4 阶段：概率、Loss 与 Gradient

Logit、Sigmoid、Cross Entropy、Gradient 与 Backpropagation

LogitSigmoidCross EntropyGradient 与 Backpropagation

一、把训练黑箱打开：从输入到参数更新的完整链条

X → z(Logit) → Sigmoid → p → Cross Entropy → Loss → Gradient → Optimizer → 参数更新

这一阶段回答：模型为什么输出 0.73？这个数字从哪里来？Loss 为什么能惩罚“自信地答错”？Gradient 又怎样把最终错误传给不同参数？

二、Logit：模型内部先得到一个不受 0～1 限制的原始评分

仍用最简单线性模型：

z = w₁x₁ + w₂x₂ + w₃x₃ + b

z 可以是 -5、-1、0、2、8，并不天然是概率。直觉：

z 很大正数 → 更倾向风险
z 很大负数 → 更倾向无风险
z ≈ 0      → 比较犹豫

这个 z 就是 Logit。它是模型内部的“原始证据分数”。

三、Sigmoid：把任意实数压缩到 0～1

σ(z) = 1 / (1 + e^(-z))
Logit zSigmoid(z)
-5≈0.007
-2≈0.12
00.50
2≈0.88
5≈0.993

于是一个二分类模型可以写成：

p = P(Y=1|X) = σ(wᵀX + b)

这就是 Logistic Regression 的核心形式。现代神经网络最后做二分类，也常有类似的“Logit → 概率”结构。

注意 Calibration：

模型输出 0.82 不天然等于现实世界“真的有 82% 违规概率”。如果希望 0.8 预测的一批样本最终约 80% 为真，还需要概率校准。

四、Binary Cross Entropy：为什么“非常自信地答错”惩罚更大？

L = -[ y·log(p) + (1-y)·log(1-p) ]

看起来复杂，但只有两种情况：

当 y=1
L = -log(p)

正确类别概率越接近 1，Loss 越小。

当 y=0
L = -log(1-p)

模型越把概率推向 0，Loss 越小。

真实 y=1 时的典型 Loss

pLoss=-log(p)直觉
0.99≈0.01非常好
0.90≈0.105不错
0.50≈0.693犹豫
0.20≈1.609明显错
0.01≈4.605非常自信地错
Cross Entropy 的核心直觉：让模型把越来越多概率质量放到正确答案上，并强烈惩罚“对正确类别给极低概率”。

五、Gradient：Loss 已经知道“错多少”，接下来要知道“参数往哪改”

对于一个参数 w：

dL/dw

它表示：如果 w 稍微增加一点，Loss 会怎样变化。

  • dL/dw > 0：w 增大会让 Loss 增大，所以为了下降，w 应减小。
  • dL/dw < 0：w 增大会让 Loss 减小，所以可以增大 w。

梯度同时提供方向 + 敏感程度。梯度下降：

w(new) = w(old) - η · ∂L/∂w

六、Sigmoid + Cross Entropy 为什么特别漂亮？从 p-y 到 Backpropagation

对 Sigmoid + Binary Cross Entropy，Loss 对 Logit 的导数可以简化为：

∂L/∂z = p - y

直觉非常清楚：

  • y=1，p=0.2 → p-y=-0.8：错误很大，要强烈推动风险方向。
  • y=1，p=0.95 → -0.05：已经很好，只需小调整。
  • y=0，p=0.9 → +0.9：模型非常自信地错，需要大调整。

如果：

z = w₁x₁ + w₂x₂ + w₃x₃ + b

通过链式法则：

∂L/∂w₁ = (p-y)·x₁ ∂L/∂w₂ = (p-y)·x₂ ∂L/∂w₃ = (p-y)·x₃

这已经是 Backpropagation 的核心直觉：最终错误沿计算图向后传播，把“责任”分配给每一个参与预测的参数。

七、Forward、Backward、Optimizer：神经网络再大，学习骨架也没变

Forward Pass：X → Layer1 → Layer2 → … → Logit → Prediction
Loss：预测 vs 正确答案
Backward Pass：Loss → 最后一层 → … → 第一层，计算每个参数 Gradient
Optimizer：根据 Gradient 更新 Parameters
Gradient

导航：告诉你坡度与方向。

Optimizer

走路方法：SGD、Adam、AdamW 等。

Credit Assignment Problem：

真正困难的不是“知道模型错了”，而是数十亿参数里哪些参数该为这次错误负责。Backpropagation 就是在做信用/责任分配。

八、Loss 和 Metric 不是一回事

第三阶段学了 Precision / Recall / F1，现在又用了 Cross Entropy。两者职责不同：

概念用途特点
Loss直接训练参数通常连续、可微，适合计算 Gradient
Metric业务评价可以包含阈值和离散规则，不一定可微

即使业务最看重 Recall，训练也可能用 Cross Entropy，再通过 Class Weight、Focal Loss、采样和 Threshold 让系统更重视漏报。

业务指标和训练 Loss 有关系，但不一定是同一个东西。

十、本阶段 5 个专家核心心智模型

  1. Score 与 Decision 分离：模型先形成连续评分，业务再依据成本切阈值。
  2. Loss 定义“什么错得更严重”：优化目标塑造模型行为。
  3. Gradient 是信用分配机制：告诉每个参数该往哪里、改多少。
  4. 学习是微小更新的累积：单个样本只是轻轻推动参数。
  5. Confidence ≠ Truth：高置信度仍需校准、证据和外部验证。

十一、完整政府采购训练例子：一条样本怎样改变参数？

样本：

X：供应商必须在本市设立分公司
Y：1

模型当前预测：

z=-2 → Sigmoid(z)≈0.12 → p≈0.12

模型严重低估风险。于是 Cross Entropy 较高，而且：

p-y = 0.12 - 1 = -0.88

错误信号通过 Backpropagation 传给相关参数。假设这个样本主要激活“本地机构”特征，则对应权重被推动调整。重复大量样本后：

p：0.12 → 0.27 → 0.62 → 0.88 …
经验 → 错误 → 反馈 → 梯度 → 参数 → 能力。

十二、深化理解：从一个梯度公式看到“知识进入参数”的全过程

1. 用具体数值更新一次 w₂

样本“必须在本市设立分公司”，设 X=[0,1,0]，y=1，当前 p=0.2：

p-y = -0.8 ∂L/∂w₂ = (p-y)·x₂ = -0.8×1 = -0.8

如果 Learning Rate η=0.1：

w₂(new) = w₂(old) - 0.1×(-0.8) = w₂(old) + 0.08

下一次相似输入的 Logit 会更容易变大，风险概率也会提高。这个“+0.08”就是一条经验对参数世界产生的微小痕迹。

2. 为什么一个样本不等于一条永久规则？

因为下一批样本还会继续推参数。如果只根据一条案例巨大更新，模型会极不稳定。现代训练就是大量样本不断“拉扯”参数，最终在数据分布和 Loss 共同作用下形成折中表示。

3. 为什么不能简单把 Recall 直接当普通 Loss？

Recall 依赖 Threshold 和离散计数。p 从 0.499 变到 0.501 时，分类可能突然从 0 跳到 1；这种函数不适合普通梯度下降直接求连续梯度。Cross Entropy 等可微 Loss 提供细腻的训练信号，再用 Threshold/Metric 评价业务结果。

4. Score、Probability 与现实概率的区别

模型输出 0.9，可能只是模型在自身训练分布下非常确信。如果部署进入完全没见过的领域，0.9 也可能不可靠。需要校准、OOD 检测、证据检索和人工机制共同约束。

5. 从 Logistic Regression 到 70B LLM，本质没有变

小模型：X → z → p → Loss → Gradient → 更新少量参数
神经网络：X → Layer1 → … → LayerN → Loss → Backprop → 更新百万/亿参数
LLM：Tokens → Transformer Blocks → Token logits → Cross Entropy → Backprop → 更新数十亿参数
规模变了、表示变了、计算图变深了，但“Forward → Loss → Backward → Update”没有变。
